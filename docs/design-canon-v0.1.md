# Northstar Linux Design Canon v0.1

## Identity

Northstar Linux is an Ubuntu-based Linux distro with a late-90s desktop feel. It is inspired by the usability, color personality, and structural clarity of classic desktop systems, while maintaining a distinct identity of its own.

## Product Family

- **OS:** Northstar Linux
- **Browser:** Lighthouse Browser
- **Launcher:** Launch
- **BBS:** Northstar BBS

## Core Traits

- Familiar
- Solid
- Clear
- Practical
- Warm
- Desktop-first
- Retro without imitation

## Visual Direction

- Windows 95 era desktop feel
- Netscape Navigator inspired browser structure
- Old-school BBS as part of the retro computing experience
- Strong title bars, clear borders, and dense desktop layout
- Minimal animation
- No blur, no glass, no modern rounded UI style by default

## Theme Direction

Northstar Linux should support classic late-90s style color themes.

### Official theme families

- **Northstar Classic**
  - blue title bars
  - cool gray surfaces
  - teal desktop mood

- **Northstar Lilac**
  - lavender-gray surfaces
  - violet title bars
  - playful late-90s palette

- **Lighthouse Teal**
  - sea-teal and slate-blue palette
  - calmer maritime tone

## Desktop Rules

- Bottom taskbar by default
- Launcher button on the left labeled **Launch**
- Rectangular taskbar buttons
- Visible active and inactive window states
- Clear desktop icons
- Simple wallpaper by default
- Scenic wallpaper allowed as an alternate, not the main default
- Desktop should feel structured, practical, and friendly

## Signature Desktop Icons

- **Launch:** Northstar symbol
- **Home:** bahay kubo
- **File Explorer:** briefcase
- **Network:** retro CRT-style network icon
- **Trash:** old metal trash can
- **Browser:** lighthouse emblem

## Lighthouse Browser Rules

Lighthouse Browser should feel structurally inspired by Netscape Navigator, but should remain visually distinct.

### Browser structure

- Title bar
- Menu bar
- Dense labeled toolbar
- Location field row
- Optional bookmarks row
- Content area
- Status bar

### Browser character

- Bright, clear, and practical
- No oversized modern UI elements
- No minimal blank chrome
- Lighthouse emblem integrated into browser identity, not pasted decoratively

## BBS Rules

Northstar BBS should be treated as part of the distro’s identity, not as a random extra.

### BBS character

- Old-school bulletin board feel
- Terminal or classic text-heavy presentation
- Practical and nostalgic
- Fits the overall retro desktop personality

## Wallpaper Rules

- Default wallpaper should be simple and not distracting
- Flat color or light gradient preferred
- Alternate wallpapers may be more scenic
- Avoid loud, busy, or overly modern wallpaper styles

## Icon Rules

- Readable at small sizes
- Strong silhouettes
- Slightly colorful
- Late-90s desktop style
- Avoid glossy modern icon style
- Avoid over-detailing

## North Star Test

Before approving any visual element, ask:

Does this feel like a dependable late-90s desktop system with its own identity, rather than a direct copy of Windows 95 or Netscape Navigator?
