# Northstar Linux

Ubuntu-based Linux distro with a late-90s desktop feel, featuring Northstar Linux and Lighthouse Browser.

## Vision

Northstar Linux is a retro-inspired Linux project built on Ubuntu, designed to bring back the clarity, warmth, and personality of late-90s desktop computing while maintaining a distinct identity of its own.

## Core Identity

- **Distro:** Northstar Linux
- **Browser:** Lighthouse Browser
- **Launcher:** Launch

## Design Direction

- Windows 95 era desktop feel
- Netscape Navigator inspired browser structure
- Classic theme colors including lilac, blue, and teal
- Desktop-first layout with strong visual identity
- Old-school BBS as part of the overall retro computing experience
